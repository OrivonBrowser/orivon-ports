Orivon Status

Everything below is fetched and checked by this page, in your browser, just now: names on Ethereum, records and pages through public IPFS gateways. A site row says Works only when its page (index.html) arrived whole and matched its hash, and a release row only when every file's sampled blocks did.

Every check is an ordinary HTTPS request from this page: Ethereum RPCs for names, public IPFS gateways and the public routing service for records and files, and GitHub for pins and releases. Each block is hashed here and compared with its address.

A checked file proves the file is served, not that it is safe to run.
