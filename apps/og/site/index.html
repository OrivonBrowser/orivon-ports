This page makes no request to any server of its own. In Orivon it reads Ethereum through your own light client. In a wallet extension, the reads go through that extension's RPC provider, which sees every name the page asks about. It reaches a private-send relay only when you turn that switch on.

The page is plain source, served as written. Orivon opens .og names through this site's resolver: add it from the Uses page, then type name.og in the address bar.
